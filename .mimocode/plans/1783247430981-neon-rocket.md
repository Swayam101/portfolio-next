# Image Manager for Admin Editor

## Problem
When editing blog posts in the admin panel, images are buried inside raw YAML text. The user needs to see all images at a glance — with their titles, descriptions, and current URLs — and quickly replace placeholder URLs with real ones.

## Current State
- Editor has two tabs: "YAML Editor" and "Post Settings"
- YAML Editor has a textarea + live preview split pane
- The preview (`YamlPreview.tsx`) only shows a placeholder line like "2 component(s)" for IMAGE components
- No way to see image thumbnails or manage URLs without scrolling through YAML text

## Solution
Add a new **"Images"** tab to the editor that provides a visual image management panel.

## Files to Create
- `src/app/admin/components/ImageManager.tsx` — The new component

## Files to Modify
- `src/app/admin/components/EditorView.tsx` — Add "Images" tab, pass yaml + onYamlChange
- `src/app/admin/types.ts` — Add `AdminImage` interface

## Component Design: `ImageManager`

### Data Extraction
Parse the current YAML using `js-yaml` (already imported in `YamlPreview.tsx`). Walk through SECTIONS → COMPONENTS, find all entries with `type: "IMAGE"` (or nested `IMAGE: {...}` shape). Extract:
- `sectionNum` — which section it belongs to
- `sectionTitle` — section heading
- `figureNum` — sequential image number across the document
- `TITLE`, `DESCRIPTION`, `ASPECT`, `PLACEMENT`, `SRC` — the image fields
- `yamlPath` — enough context to locate and replace the SRC string in the raw YAML

### Replacement Strategy
Since YAML editing needs to preserve formatting and indentation, the approach is:
1. For each image, find the `SRC: "..."` line within its component block in the raw YAML
2. Use `String.replace()` with a targeted pattern that matches the old SRC value
3. Return the modified YAML string back to the parent

The pattern to find each image's SRC: look for the line containing `SRC:` that follows the image's TITLE in the YAML text. A simpler approach — since each IMAGE component has a unique TITLE — is to find the block starting at the TITLE line and replace the SRC line within that block.

### UI Layout
Each image renders as a card with:
- Figure number badge ("Fig. 1", "Fig. 2", etc.)
- Thumbnail preview area (shows actual image if SRC is a valid URL, placeholder box if not)
- TITLE and DESCRIPTION text
- ASPECT and PLACEMENT as small badges
- Section reference ("§ I — Section Title")
- Editable SRC input field with a "paste URL" button
- When the user types/pastes a new URL, the YAML is updated in real-time

### Empty State
When no IMAGE components exist in the YAML, show a message: "No images found. Add images using the Quick Insert toolbar in the YAML Editor tab."

## Tab Integration
Add "Images" as a third tab in the EditorView tab bar, positioned between "YAML Editor" and "Post Settings". When this tab is active, render the ImageManager component with the current YAML and an onChange callback that updates the YAML state.

The tab should show a count badge (e.g. "Images (3)") so the user knows how many images are in the post.

## Styling
Follow the existing admin panel dark theme (#0d1b24 background, #5bbfbf teal accents, monospace labels). Image cards use #111f2a background with subtle teal borders on hover — consistent with DashboardView post rows.

## Verification
1. Create a new post with the Quick Insert "Image" button → switch to Images tab → should show the image card
2. Enter a real image URL in the SRC field → thumbnail should appear
3. Check that the YAML textarea (switch back to YAML Editor tab) reflects the updated URL
4. Edit an existing post with multiple images across sections → verify all images appear with correct section references
5. Test with both flat (`type: "IMAGE"`) and nested (`IMAGE: {...}`) YAML formats
6. Verify the empty state when YAML has no IMAGE components
